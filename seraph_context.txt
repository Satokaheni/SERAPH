SERAPH — Full Resume Context

What it is: A novel NLP research pipeline targeting ACL/EMNLP/NAACL. The core claim: self-simulation grounded in cognitive psychology measurably improves empathy alignment scores vs SOTA baselines. Before generating any response, the agent asks: "If I were a human feeling [emotion] at [intensity] in [context], how would this response feel to me?" Grounded in Simulation Theory, BDI Modeling, Gross's Emotion Regulation Model, Plutchik's Wheel, and Mirror Neuron Theory. This has not been formally implemented or benchmarked end-to-end in the literature — that is the novel contribution.

The 5-stage pipeline:

Stage 1 (Haiku) — raw emotional signal extraction, no labeling yet
Stage 2 (Haiku) — Plutchik classification + VAD scores + BDI sketch + Gross regulation state
Stage 3 (Sonnet) — Self-Simulation Core ← the novel contribution, 7-step first-person simulation
Stage 4 (Sonnet) — Ethical Gate: APPROVE / MODIFY / BLOCK
Stage 5 (Sonnet) — empathy-informed response + EmpathicReasoningExplanation for transparency

No training required — all intelligence comes from Anthropic's models via structured prompting and pipeline architecture.

Tech stack: Python 3.10+, Anthropic API, Pydantic v2, scikit-learn, HuggingFace datasets, scipy. PyTorch optional (DialogueRNN checkpoint mode only). Runs on Windows, macOS, Linux, and Lambda Labs GPU instances.

Key design decisions already made:

USE_BATCH_API = True in config.py — default for all benchmark runs
USE_BATCH_API = False for local test runs with --sample-limit 5
All paths use PATHS.* from paths.py — never hardcoded strings
All file I/O uses encoding="utf-8" explicitly — Windows cp1252 safe
get_torch_device() in paths.py — auto-selects CUDA or CPU
Pickle protocol 4 — cross-platform model serialization


Datasets:

MELD — freely downloadable, python data/prepare_datasets.py --dataset meld
EmpatheticDialogues — freely downloadable via HuggingFace
IEMOCAP — manual license required from sail.usc.edu/iemocap, place at data/raw/IEMOCAP_full_release/

API: Anthropic API (separate from Claude.ai Pro). Get key at console.anthropic.com. Recommended starting budget: $50 for local testing, top up to $150-200 for full experiment. USE_BATCH_API=True is critical — cuts wall time from 10 days to ~4 hours.
